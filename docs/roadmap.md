# 🛣 Project Roadmap

# 🌱 KAZTHOR FARM

**Intelligent Greenhouse Automation Platform**

This document describes the long-term development roadmap of KAZTHOR FARM.

The project is developed incrementally, where each version introduces new hardware, firmware, software and automation capabilities.

---

# 🎯 Project Vision

KAZTHOR FARM aims to become a complete Smart Farming platform that combines:

- Embedded Systems
- IoT
- ESP32
- ESP-IDF
- FreeRTOS
- Artificial Intelligence
- Computer Vision
- Cloud Computing
- Robotics
- Precision Agriculture

Each release improves the previous version while maintaining a documented engineering process.
