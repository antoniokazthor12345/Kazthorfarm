# 🧠 Main Controller

## ESP32-S3 WROOM

The ESP32-S3 is the main controller of the system.

### Features

- Dual-core processor
- WiFi
- Bluetooth LE
- FreeRTOS support
- Multiple ADC channels
- GPIO expansion
- OTA capable
- ESP-IDF compatible
- Future camera support

### Responsibilities

- Sensor acquisition
- Climate control
- MQTT communication
- Dashboard integration
- OLED updates
- Alert management
- Automatic actuator control

# 🌡 Temperature Sensor

## DS18B20 Waterproof Sensor

Used to monitor ambient temperature.

### Specifications

- Digital 1-Wire communication
- High accuracy
- Waterproof probe
- Long cable support

### Connection

```txt
VCC  -> 3.3V
GND  -> GND
DATA -> GPIO13
```

### Additional Hardware

```txt
4.7kΩ Pull-up resistor
between DATA and 3.3V
```

# 🔄 Servo Motor

## SG90 Micro Servo

The servo motor automatically controls the airflow direction generated by the cooling fan.

### Functions

- Automatic airflow positioning
- Manual positioning from Dashboard
- Improved air distribution

### Operating Modes

#### Automatic Mode

The servo moves automatically whenever the cooling fan is activated.

#### Manual Mode

When the fan is OFF, the servo can be controlled using the UP and DOWN buttons from the dashboard.

### Connection

```txt
VCC    -> 5V
GND    -> GND
Signal -> ESP32 GPIO
```

680µF
|

# 🚿 Water Pump Protection

## 1N4007 Diode

The water pump is protected using a flyback diode.

### Purpose

- Eliminate voltage spikes
- Protect relay contacts
- Protect electronics
- Increase system reliability

### Installation

Connected in parallel with the water pump.
