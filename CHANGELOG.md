# [V3.5] - July 2026

## 🚀 Hardware Refinement & Smart Fan Update

This release focuses on improving the electrical reliability, mechanical design, and user experience of the KAZTHOR FARM platform. It introduces the first servo-assisted ventilation system, enhanced power stability, and new dashboard controls.

### ✨ Added

- SG90 servo motor for automatic fan positioning.
- Manual fan position controls (UP / DOWN) from the web dashboard.
- Automatic fan positioning mode.
- 680µF / 16V electrolytic capacitor for power stabilization.
- 1N4007 flyback protection diode for water pump relay.
- Improved transparent enclosure internal layout.
- Optimized OLED display position for better visibility.
- Enhanced cable management inside the enclosure.
- Updated hardware validation reports.
- Updated MQTT validation reports.
- Updated dashboard validation reports.
- Updated functional validation reports.
- Expanded technical documentation.

### 🔧 Improved

- Mechanical alignment of the cooling fan.
- Servo positioning accuracy.
- Airflow direction consistency.
- Relay switching reliability.
- Power supply stability during pump activation.
- Dashboard responsiveness.
- Dashboard manual control interface.
- OLED readability.
- Internal wiring organization.
- Repository structure.
- Technical documentation.

### 🛠 Fixed

- Servo instability caused by relay activation.
- Voltage fluctuations during pump switching.
- Minor dashboard synchronization issues.
- Improved cable routing inside enclosure.
- Documentation corrections and formatting improvements.
